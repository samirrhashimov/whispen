# Contributing Guidelines

Thank you for your interest in contributing to this project!

### How to Contribute
- Fork the repository and create a new branch for your feature or bug fix.
- Follow the existing code style and conventions.
- Test your changes before submitting.
- Submit a Pull Request with a clear explanation of your changes.

### Reporting Issues
- Use the GitHub Issues section to report bugs or request features.
- Provide as much detail as possible (steps to reproduce, environment, screenshots, etc.).

### Code of Conduct
By participating in this project, you agree to follow our [Code of Conduct](CODE_OF_CONDUCT.md).

### Commit Messages
- Use clear and descriptive commit messages.
- Example: `fix: resolve auth error on login`

### Questions
If you have any questions, feel free to open a discussion or contact the maintainers.
